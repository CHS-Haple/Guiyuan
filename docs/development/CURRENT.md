## Accepted behavior

- Home uses the verified native SystemUI end-side carrier; Keyguard and AOD share one host-scoped family owner; Notification Shade and fully expanded Control Center remain native. AOD never serves as a Control Center transition source.
- The standard mobile presentation remains four dots. Dual-row presentation is opt-in and requires two authoritative active subscriptions and complete SIM-slot mapping. Missing identity uses the normal single-row/native-safe fallback without discarding the dual preference; single/dual settings banks remain separately remembered.
- During eligible partial Control Center expansion, the four-dot source collapses toward its first dot, moves to a verified native anchor, spreads and grows into native geometry. Two independent roots require separately verified subscription identity. A one-root composite may use **shape-only** grouped BARS/DOTS morph if exactly two four-glyph rows are optically verified; that does not prove each native row belongs to a given SIM.
- Center 5G/5GA morphing requires a matching native glyph and source/provenance checks. Verified aggregated-root presentation can differ from the data SIM; unknown or disagreeing targets retain the bounded no-target/native fallback.
- Native FAKE/FINAL width and peer spacing are measured from their own native frames. Charging changes retarget the existing reservation writer; native final layout, alpha, translation and visibility remain SystemUI-owned.

## Ownership, cache and Hot Reload

- Every mutable native presentation property has a single owner; `SysUiPresentationOwner` owns only bounded masking/reservation changes, and releases the module's changes on session end. CC projections are host/session-scoped.
- `StatusPainter` native-resource caches and drawable optical snapshots include native resource configuration; CC mobile-target witnesses invalidate on verified mobile bind events. B1025 additionally rechecks cached native FINAL slot membership, slot identity and optical-child ancestry before reuse. B1038 adds one CC Session-owned global layout listener to detect direct native mobile root identity changes in single-display mode and reuse the existing PreDraw mobile cache invalidation; B1039 [#561](https://github.com/CHS-Haple/Guiyuan/pull/561) retains the registration-time `ViewTreeObserver` for both CC listeners and unregisters from it on Session stop, also checking a distinct live observer after a possible floating-observer merge. No polling or per-frame complete View-tree scan is added merely to cover theoretical third-party changes.
- Remote preference callback delivery does not acquire a Guiyuan binding monitor while frameworks hold their own listener lock. Feature/Visual configurations commit only for the current binding generation; retired callbacks cannot overwrite new settings. This is the bounded B1037 fix for [#554](https://github.com/CHS-Haple/Guiyuan/issues/554).
- Hot Reload validates the transfer before taking over the old Hook handles; successful generation handoff is explicit and bounded. Companion UI progress is owned by the Application, not a navigated page. Invalid transfer or failed takeover reports restart required rather than inventing a safe handoff.
- Preview Sandbox remains local simulation and does not inject fake network state into SystemUI. Integrated B1031 uses native hotspot geometry, completes the triggered Logo wave after finger release, aligns secondary-page list rebound with Home's Compose overscroll and retains the compact top bar; Sandbox refers to the data SIM as 上网卡. Do not restore the old whole-page MIUIX translation experiment (`0301a916` → `5f6a93fd`), which conflicted with top-bar blur.

## Open compatibility questions

- [#519](https://github.com/CHS-Haple/Guiyuan/issues/519): B1038 device diagnostics identify **LSPosed 2.2.1 / 7925** via API 102 and confirm one normal V9 `continuous` Hot Reload (`staleHooks=32`, `restartScope=false`, main-thread old-generation handoff). The matching [release archive identifier](https://t.me/s/LSPosedArchives/4155) is public, but a source commit for that exact binary is not verified. The payload still carries an old-generation cleanup `Runnable`, contrary to API 102's neutral-state/early-retirement contract; the inspected **Vector** implementation rejects this direct field, whereas the installed LSPosed accepted it on the observed run. No abnormal failure branch or leak was reproduced. Preserve single-writer, main-thread and fail-native contracts; do not remove deferred cleanup without a verified handoff design.
- [#521](https://github.com/CHS-Haple/Guiyuan/issues/521): B1038 also detects changed direct native mobile slot membership when a global layout event occurs during an active single-display CC transition. A replacement of an optical descendant inside the same root, or a mutation without a layout event, is still outside guaranteed detection. No universal third-party coverage or observed third-party reproduction is claimed.

These are explicit compatibility limitations, not observed regressions of the accepted SystemUI runtime baseline. Investigate only with reproducible evidence or an authoritative upstream contract; preserve Fail native.
