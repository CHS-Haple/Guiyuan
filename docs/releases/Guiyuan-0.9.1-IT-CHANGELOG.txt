限额内部测试更新日志

当前版本：0.9.1-IT（安装版本 0.9.1-internal，Build 1634）
更新范围：0.9.0-IT（Build 1239）→ 0.9.1-IT（Build 1634）

【0.9.1-IT】

一、新增

- 新增实验性 HyperOS 4 界面风格：可在 OS3、OS4 之间切换。OS4 采用全新的柔光玻璃导航栏、顶栏、搜索框、对话框、弹出菜单和操作按钮；原有 OS3 风格继续保留。
- 新增功能搜索：支持中文、英文、拼音、首字母和常用关联词搜索，可直接定位到对应设置，减少逐项查找。
- 预览沙盒新增实时预览小栏：向下浏览设置时，顶部可继续查看当前归元图标的模拟效果，并可快速返回完整预览。
- 悬浮导航栏新增触控扩展：支持标准、模糊、玻璃和液态玻璃等悬浮样式，扩大底部可点击区域，减少误触；默认开启，也可以在外观设置中关闭。

二、修复

- 修复短时间内反复热重载后，归元图标偶发变回系统原生图标，以及 Wi-Fi、移动网络制式未及时恢复的问题。
- 修复充电过程中频繁热重载或插拔充电器后，电量图标偶发停留在先前充电状态的问题。
- 修复部分状态切换及控制中心收放时，原生图标、着色与归元显示衔接异常的问题，改善锁屏、息屏显示和桌面之间的状态恢复。
- 修复应用初次连接运行服务时，个别功能设置和外观调整可能未及时生效的问题。
- 修复还原视觉默认设置时误删自定义电量配色方案的问题：还原后保留已创建的方案，并将当前配色切回系统默认方案。
- 修复单排与双排信号模式下，电量配色方案选择和实际颜色可能不一致的问题；两种模式现在共用同一套电量颜色与配色方案。
- 修复部分异常数值可能影响图标大小、位置等视觉设置的问题。

三、优化

- 优化电量配色卡片的分页操作：底部圆点可直接点击切换，也可按住滑动选页；卡片切换跟随选择即时播放，连续往返操作更流畅，并加入触感反馈。
- 调整诊断操作：点击顶部图标可导出日志，长按可分享；简洁日志中的常见状态使用中文展示，展开详情仍保留原始信息。
- 改善电量数字和网络制式的字体适配：优化系统字体变化时的字重处理，避免对无法确认的字体强行套用不匹配的效果。
- 更新依赖：AndroidX DataStore Preferences 1.2.1 → 1.3.0。

说明：本次统计仅汇总相比 0.9.0-IT（Build 1239）最终保留的变化，不包含开发中已撤回或被替代的方案。遇到问题请附复现步骤、录屏或诊断报告。

【0.9.0-IT】

一、新增

- 双排信号新增 Duo 样式：支持横向八点与经典样式切换，分别记忆位置；未开启双排时仍使用单排。
- 新增「寄生模式」：沙盒中的网络、电量状态可临时显示在系统状态栏，退出沙盒或应用异常结束后恢复真实显示。
- 新增低电量阈值：可在 5%～30% 之间调整，状态栏与沙盒预览同步生效。
- 液态玻璃新增「模糊 / 均衡 / 通透」三种质感，默认「均衡」，兼容已有设置。

二、修复

- 修复首次启用或系统字体变化后，网络制式、电量数字的字重调节可能不可用的问题。
- 修复部分情况下5GA 后缀间距不自然的问题，改善状态栏与控制中心的文字衔接。
- 修复控制中心下拉时，飞行模式、无 SIM 图标偶发错位或无法正确衔接的问题。
- 修复液态玻璃拖动结束时选中液滴回弹不连贯的问题。
- 修复主页运行卡片开关触发时的异常抽动，统一点击与按压反馈。
- 修复配置恢复失败时部分设置未完整还原的问题，并拒绝相互冲突的备份配置。
- 加强配置文件安全校验：限制导入来源，处理自定义配色名称中的异常字符，避免无效数据影响恢复。
- 完善状态模拟退出与异常停止后的恢复机制，避免模拟内容滞留在状态栏。

三、优化

- 重做主页运行卡片：运行状态与「启用模块」集中展示，开关移至卡片下方；加入随状态变化的柔和渐变，整行均可切换开关。
- 重构原生可变字体适配：分别识别网络制式和电量数字所用字体的真实字重范围，支持无级滑动、精确输入及字体变化后的重新识别。
- 优化首次使用的电量显示：尚未单独配置的电量居中布局默认显示数字，已有用户选择保持不变。
- 重做液态玻璃光效：改善折射、边缘反光和选中液滴质感；支持动态光效，手机前后、左右倾斜时，高光变化更自然。
- 优化「显示与过渡」设置：共用显示选项不再随单排、双排或内容布局重复记忆，独立位置调整继续保留。
- 调整首页与预览沙盒的布局及提示文案，让运行状态、状态模拟和网络、电量预览更清晰。
- 改进控制中心动态过渡：优化原生字体、图标位置和状态变化时的衔接，减少下拉过程中的跳变。
- 完善热重载及配置同步时的状态交接，提高连续操作和异常情况下的稳定性。
- 更新依赖：AndroidX Core 1.17.0 → 1.19.1；kotlinx.serialization Core / JSON 1.11.0 → 1.12.0。
- 更新构建工具：Gradle 9.8.1 → 9.8.2；
- 液态玻璃改用 MIUIX Blur，移除 Backdrop 2.0.1、Shapes 1.2.1。

说明：仅汇总相对上一内测版本最终保留的变化。遇到问题请附复现步骤、录屏或诊断报告。

【0.8.0-IT】

一、新增

- Wi-Fi 与飞行模式粗细调节：新增 60%～130% 的图标粗细设置，以系统原生图标为基础调整线条，并适配控制中心下拉过渡。
- 电量数字与网络制式字重调节：支持 200～1000 原生字重、每档 50；电量数字、4G/5G/5GA 等网络文字可分别设置，默认保持 600。
- 配置备份与恢复：支持导出和导入功能设置、单排与双排的独立视觉配置及自定义电量配色，方便更换版本或重新配置时恢复常用设置。
- 界面缩放：可在 80%～110% 之间调整归元应用界面大小，不改变系统整体显示缩放或状态栏实际尺寸。
- 网络图标独立偏移：在电量居中布局中，可分别调节 Wi-Fi 和移动网络图标的上下位置，保留原有配置。

二、修复

- 强化配置导入安全：严格校验 JSON 结构、字段类型、配置范围与文件编码，拒绝异常或伪造的配置数据；恢复失败时回滚相关设置，避免留下不完整状态。
- 修复历史字重配置的兼容问题：旧配置中合法的超范围字重会转换至新上限，单排、双排及不同布局分别处理，不影响其他视觉设置。
- 修复控制中心原生目标变更后，部分图标仍使用旧位置或外观的问题；在确认原生图标重新绑定时及时更新匹配缓存。
- 修复控制中心界面重建或监听对象变化时，部分布局与预绘制监听未从原注册对象正确释放的问题。
- 修复远程设置同步过程中可能出现的锁竞争及旧回调覆盖新配置的问题，改善热重载和配置切换时的稳定性。
- 修复连接其他设备热点时，Wi-Fi 图标的缩放与系统原生轮廓不完全一致的问题，改按已确认的热点图标边界进行匹配。
- 修复部分内容不足一页的设置页面仍触发无意义滚动结束触感的问题，使短页面的交互反馈更自然。

三、优化

- 重构文字字重渲染算法：电量数字与网络制式统一采用原生字体字重轴，不再使用额外描边模拟加粗；同步优化字重插值、文字定位与 5GA 下标的绘制衔接。
- 优化图标缩放与描边算法：针对 Wi-Fi、飞行模式建立可调粗细计算，兼顾不同尺寸下的图标轮廓、视觉比例及控制中心过渡表现。
- 优化控制中心动态过渡算法：改进原生文字字体、图标目标和几何边界的识别与匹配，减少下拉过程中形态、粗细或位置衔接不一致的情况；无法确认目标时仍保留系统原生显示。
- 统一预览沙盒与实际绘制规则：电量数字、网络制式的字重和缩放逻辑复用同一绘制链路，减少预览与实际效果的规则差异。
- 升级 MIUIX 上游组件，优化部分设置页面的滚动、顶栏衔接、越界回弹及交互细节，并完善左侧语义图标和中英文说明。
- 优化「关于」页动态标识的文字流光与涟漪联动，使长按触发的波纹效果在松手后仍能自然结束。
- 完善诊断信息：增加实际 Xposed 框架名称与版本识别，方便区分不同框架环境下的兼容性问题。

说明：本次仅统计相对 0.7.0-IT（Build 1024）最终保留至 0.8.0-IT（Build 1110）的新增、修复与优化，不包含中途撤回、被替代或重复实现的实验。内测适配仍以已验证的 Xiaomi HyperOS / SystemUI 环境为准；5GA、其他系统版本与第三方状态栏样式的实际效果可能存在差异。遇到问题请附复现步骤、录屏及「诊断」报告。

【0.7.0-IT】

一、新增

- 双排信号显示：支持将 SIM1、SIM2 的信号分别显示为内外两排四点。默认关闭；仅在系统确认两张 SIM 均有效且卡槽对应关系完整时启用，否则使用单排显示。
- 单排与双排独立配置：分别记忆显示布局、大小、电量与信号配色等设置。首次开启双排时继承现有配置，此后切换互不覆盖。
- 双排信号过渡：支持与控制中心已确认的聚合信号图标或两张独立信号图标衔接；无法可靠识别原生目标时交还系统显示。
- 双卡预览模拟：可切换无卡、仅 SIM1、仅 SIM2、双卡四种状态，分别设置两张卡的信号强度和网络制式，并模拟默认流量卡切换。
- 静态作用域详情页：在「关于」中查看 SystemUI、系统设置对应的作用域用途、安装版本与授权状态。
- 电池配色可视化选色：增加连续色盘，拖动时实时预览颜色；支持常用颜色、色相/饱和度/明度调节及 HEX、RGB 输入。

二、修复

- 修复关闭移动数据后，4G/5G 等网络制式文字未及时消失的问题；SIM 信号仍按实际状态显示。
- 修复部分 SIM 信息更新不同步、原生信号图标尚未绑定完整时可能出现的信号误判；无法确认替代图标时保留系统原生显示。
- 修复双卡非聚合布局同时开启 Wi-Fi 时，下拉控制中心引起的左侧原生图标位置偏移。
- 修复控制中心下拉期间充电状态变化时，原生图标间距和动画终点发生跳变的问题。
- 修复缺少有效原生电量数字目标时，电量环退出动画可能错误匹配的问题；保留电量环的收缩过程。
- 修复系统配置变化或移动网络图标重新绑定后，部分动画仍使用旧图标位置、尺寸或外观的问题。
- 修复系统设置进程未运行时，已授权作用域可能被误判为未授权的问题。
- 修复切换页面后热重载进度显示中断的问题；热重载进行中仍保持正确的操作状态。
- 加强热重载异常交接处理：提前校验新旧运行实例的交接数据；交接无效时提示重启 SystemUI，避免继续使用不完整的接管状态。

三、优化

- 重做四点信号的控制中心过渡：四点依次收至最左侧，移动至原生信号位置后重新展开，再生长为信号柱；收回时反向衔接。
- 调整双排信号的点径、间距和整体位置；单张 SIM 信号状态未知时只弱化对应的一排，不影响另一排。
- 重整预览沙盒的网络控制：提供「无 / 移动网络 / Wi-Fi」三种模式，各模式均可独立调整 SIM 信号；整理双卡选项顺序和信息排版。
- 调整主页运行状态的 MIUIX 进度环：统一加载旋转、状态切换和回弹动画。
- 调整「关于」页涟漪经过标题与版本文字时的流光方向，使光效跟随波纹扩散。
- 扩充双卡诊断信息：记录系统识别的卡槽、信号来源及控制中心原生图标匹配情况，便于排查显示与过渡异常。
- 减少控制中心动画绘制时的重复原生目标读取，以及电池选色时未发生变化的重复设置写入。

说明：以上仅包含相对 0.6.1-IT 的最终整合变化，不包含开发期间已撤回或被替代的实验。兼容性以已验证的 Xiaomi HyperOS / SystemUI 环境为准；其他系统版本和第三方状态栏样式可能存在差异。遇到问题请附复现步骤、录屏及「诊断」报告。

【0.6.1-IT】

一、新增

- 设置快捷入口：支持在手机「设置」中添加归元入口，可选择顶部、中部或底部位置，并提供两种图标样式。默认关闭；首次启用时才按需申请「设置」作用域，不影响原有 SystemUI 作用域。
- 关于页动态标识：重新设计归元标识及背景光效。长按标识会产生向外扩散的涟漪，波纹经过标题和版本号时带动文字变化，并呈现流光效果。

二、修复

- 修复已复现的部分锁屏与 AOD 切换问题：调整三合一图标退出、原生电池恢复与图标布局交接顺序，改善短暂露出原生图标和左侧间距异常的情况。
- 修复锁屏/AOD 容器重新挂载后，原生图标透明度监听未及时重新绑定的问题。
- 改进控制中心收放及原生状态栏切换的部分异常路径，减少三合一与原生图标交接时的突兀显示；完全展开的控制中心仍由系统原生负责。
- 修复部分网络文字过渡异常：完善 5G/5GA 与原生目标的识别和对齐；缺少可靠的动画终点时改为整体淡出，避免强行匹配造成的裁切和跳变。
- 改进双卡、流量卡及 SIM 状态变化时的网络更新逻辑，减少网络制式与实际数据来源不一致造成的显示或过渡错误。
- 修复部分电量环退出及充电状态切换时的过渡不自然问题，协调电量环、充电闪电图标与原生状态的衔接。
- 修复部分热重载场景下 Wi-Fi、移动网络状态接续不及时的问题，完善模块新旧运行实例之间的状态恢复。
- 修复框架服务重连、授权回调及设置同步中的部分时序问题，避免过期回调干扰当前操作，并减少不必要的重复写入。
- 修复诊断日志在长内容截取、热重载跨会话归属等情况下的整理异常，保留有助于排查的原始信息。

三、优化

- 将原有「重启 SystemUI」扩展为「重启作用域」：可单独选择 SystemUI、设置，或同时选择两者；只展示已授权作用域，并提示具体失败目标。重启「设置」只结束其进程，不会主动打开设置页面。
- 完善主页运行状态卡片：在适用状态下可点击重启 SystemUI，或引导申请 Xposed 作用域；同时优化状态文案与操作反馈。
- 优化「关于」页的系统信息与作用域展示：统一为「设置」名称，状态采用「已连接 / 未启用 / 未安装 / 异常」。已授权作用域不会因入口功能关闭而显示未连接；仅明确异常时强调状态颜色。
- 优化「关于」页的滚动收合、越界回弹、文字排布和内容间距，使顶部标识与信息区域的过渡更自然。
- 完善设置页、功能页和相关弹窗的 MIUIX 控件样式、语义图标、分隔符、间距及中英文文案。
- 优化部分分档滑条的吸附与触感反馈，让拖动到关键档位时的操作感更明确。
- 改善液态导航栏在窗口宽度和布局方向变化时的适配，保持导航选中效果与滑动位置一致。
